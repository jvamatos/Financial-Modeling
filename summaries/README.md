## Como estudar cada lecture

1. Faz o **Testa-te** primeiro, sem ver as respostas.
2. Lê as notas, com o notebook aberto no Colab, focando no que erraste.
3. Refaz as células *Practice* do notebook sem olhar para as soluções.
4. Repete o Testa-te.

O formulário do exame está em [`reference/2270_Formulae.pdf`](../reference/2270_Formulae.pdf).
